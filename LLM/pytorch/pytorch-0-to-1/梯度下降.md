gradient descent

```python
w = 1
def gradient(xs, ys):
    grad = 0
    for x, y in zip(xs, ys):
        grad += 2 * x * (x * w - y)
    return grad / len(xs)

for epoch in range(100):
    grad = gradient(xs, ys)
    # learning rate is 0.01
    # if the gradient becomes larger, we should decrease the learning rate
    w = w - 0.01 * grad
    print(f"Epoch {epoch}, w: {w}, loss: {loss(w)}")
```  

stochastic gradient descent
随机梯度下降 - 每次只用一个数据点来计算梯度

w = w - learning_rate * d(loss)/d(w)

```python
w = 1
def stochastic_gradient(x, y):
    return 2 * x * (x * w - y)

for epoch in range(100):
    for x, y in zip(xs, ys):
        grad = stochastic_gradient(x, y)
        w = w - 0.01 * grad
        print(f"Epoch {epoch}, w: {w}, loss: {loss(w)}")
```
